S3 · A SYNTHETIC Round A in the demo store

The demo builder now writes a whole labelled-synthetic Round A: 7 selections, 24 trainings and evaluations, 48 verdicts and the step4 summary, all through the real code.

ACs 5/5 Depends on S1, S2 Data demo is SYNTHETIC; no real Round A yet

In plain words

The server has not run Round A yet, so the page needed something to show. The demo builder now creates a complete, invented Round A in the demo store: the same 7 ways of removing episodes, 3 seeds each, judged by the same verdict code the server will use. Only the robot attempts themselves are invented, drawn from a generator whose planted effects are written out in words on every run. Every run is tagged synthetic.

I did not tune the invented effects until the headline looked like a win. The first tries, where the reliability-curated policy completes more attempts, made it win on speed too, so the two curations did not trade off. The demo therefore honestly says not shown. It demonstrates that the page and the wording behave, not that the idea works.

Terms are defined in the glossary of the main report.

Why

PoC §10 (p. 20) lists a “dashboard linking failed rollouts to influential episodes” and counterfactual removal tests; the brief asked for a labelled synthetic demo until the server runs, with the drop-in proof (S5) that real runs render with no code change.

Divergences and limitations

  • Recorded divergence: the demo ranks each task by the all-rollout column harm_<m>, not the per-task column harm_<m>__same_task. The demo's invented rollouts cover only 2 of the 20 tasks, so the per-task columns are empty (NaN) for the other 18 and the select step refuses (measured: LineageError: score table has NaN in 'harm_f30__same_task'). The select run records the column it used and the page's caption says “rollouts: all”. The server ranks by __same_task; S5 exercises that column through the real stage commands. Owner option: build invented rollouts for all 20 tasks.
  • Family-O verdicts are not built in the demo (the demo rollouts carry no operation pairs); the page shows a “none recorded” line for them, and S5 covers O on a server-shaped chain.
  • The invented rollouts cover only part of the picture by design; none of this says anything about a real policy.
