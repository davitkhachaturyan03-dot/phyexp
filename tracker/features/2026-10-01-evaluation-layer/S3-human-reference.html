S3 · LIBERO on this Mac, and the human reference from LIBERO's own goal check

The LIBERO simulator now runs locally, which LeRobot's docs say needs Linux. Replaying the stored states of all 1000 demos through LIBERO's goal predicate gives each demo's real time to success. The old anchor, demo length (duration_s), overstated it and would have inflated every HRT by 1.162× (libero_spatial) and 1.049× (libero_10).

ACs 8/8 met Depends on — (S1 for the summary metrics)

Why

"Human reference = durations of LIBERO's original human-teleoperated demonstrations on the same tasks." — PoC §3.5 A, p. 8
"For each rollout, record whether and when it succeeded, using the benchmark's goal check." — PoC §9.1 Step 2, p. 18

Planning checked how the catalog's duration_s was produced before treating it as the human T (plan P6–P8). LIBERO's scripts/create_dataset.py sets rewards[-1] = 1 unconditionally (quoted, commit 8f1084e, l. 228–231), so the stored reward is not a goal check. Human collection stops only after the goal has held for 10 consecutive steps (task_completion_hold_count = 10, quoted). So demo length includes a success-hold tail, and the anchor has to come from the predicate itself.

Divergences and limitations

  • Unexpected premise: LIBERO runs on macOS. LeRobot's docs say "LIBERO requires Linux (sys_platform == 'linux')" (quoted). The plain install does fail (robomimic → egl-probe needs CMake), but hf-libero --no-deps plus robosuite, bddl, mujoco 3.8.1 and numba installed into the main .venv (32 packages added, none changed) runs predicates and offscreen rendering (measured).
  • Unexpected premise: LIBERO's reward is hard-coded (rewards[-1] = 1). "No failed demos" still holds, but the evidence is the 1000/1000 replay, not the reward. CLAUDE.md and vla-build were corrected by the orchestrator.
  • Alignment (approximate by design). Human T counts from stored state 0, which is original step 5 (cap_index = 5). Rollout T counts from the post-settle state (LeRobot's 10 no-op steps). The residual is ≤ 5 steps = 0.25 s (inferred). As PoC p. 8 says, demos and rollouts do not share initial states.
  • Two scenes. The human reference uses each demo's own model XML. Rollouts run in the BDDL-built scene that LeRobot uses. In the BDDL scene 3/1000 demos never reach the goal, and the BDDL replay is not deterministic across resets of one env (the mechanism is in S5).
  • 12/1000 demos stop satisfying the goal in their last 1–2 stored states. T = first success is unaffected, which matches LeRobot rollouts terminating on the first check_success().
  • The replay took 10,405.7 s, not the planned 2–3 min. The median per-demo cost was 3.9 s; the long tail coincided with a session stall (inferred). It was not re-run.
  • The HRT anchor is fixed: all 1000 v0 originals, for every compared policy (owner default). Using each training subset's own demos would move HRT's denominator between counterfactual arms.
