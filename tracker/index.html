All 1000 LIBERO demos (libero_spatial + libero_10, 200,340 frames, 0 dropped) in one lossless LeRobot v3 dataset, each episode bit-exact to raw (1000/1000) with a stable ID and content hash. Derived versions keep ground truth apart (v1: 100 changed / 900 identical). Every stage is an MLflow run, so diff shows two runs differ by exactly 20 removed episode versions and nothing else.
